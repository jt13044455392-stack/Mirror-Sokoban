# 镜像推箱子 (Mirror Sokoban)

> 一个探索空间映射与多界协同的推箱子解谜系统。

🎮 **在线试玩地址**：[https://jt13044455392-stack.github.io/Mirror-Sokoban/](https://jt13044455392-stack.github.io/Mirror-Sokoban/)

无需下载安装，支持电脑与手机现代浏览器点开即玩！

---

## 核心游戏规则

1. **镜像联动 (Vertical Mirror Mapping)**
   - 现实角色与镜像角色同时响应玩家输入。
   - 上下输入保持一致（`W/S` 同为上下），左右输入相互镜像（`A` 向左时镜像向右，`D` 向右时镜像向左）。
2. **独立结算与借墙停顿 (Wall Stall)**
   - 两侧世界拥有各自独立的物理判定。
   - 当一侧角色撞墙停下时，**不会打断**另一侧角色的推箱与移动。巧用“借墙停顿”是调整双侧步调与相对相位的核心技巧！
3. **多世界机关机制**
   - 随着章节推进，游戏逐步引入共轭镜闸、封存回路、动态路由、跨世界桥等丰富机制。

---

## 操作指南

| 按键 | 功能 |
| :--- | :--- |
| **W / A / S / D** 或 **↑ / ← / ↓ / →** | 控制角色移动与推箱 |
| **Z** | 撤销上一步 (Undo) |
| **R** | 重置当前关卡 (Restart) |
| **章节与关卡标签** | 自由切换已解锁的各章节及特殊试验关卡 |

## 包含章节

- **第 1 章：垂直镜像基础**（单侧借墙与相位调校）
- **第 2 章：多箱协同推进**
- **第 3 章：经典原子对撞**
- **第 4 章：深层几何阻隔**
- **第 5 章：三界与扩展拓扑**
- **第 6 章：极限耦合精选**
- **进阶原型关卡**：共轭镜闸 (Ch.7)、封存镜闸 (Ch.8)、定向镜闸 (Ch.9)、镜闸路由网 (Ch.10)、节拍镜闸 (Ch.11)、跨世界桥 (Ch.12) 及衍生试验场。
